# MiG-29 Radar Sim

Интерактивный симулятор работы бортовой РЛС (радиолокационной станции) с визуализацией диаграммы сканирования, зоны обзора и обнаружения воздушных целей. В качестве первого образца взята РЛС истребителя **МиГ-29** (комплекс «Слот» / Н019).

Проект написан на **Vue 3 + TypeScript + Pinia**, 3D-сцена построена на **Three.js**, а экраны индикации (PPI/B-Scope, боковая проекция) отрисовываются на **Canvas 2D**.

## Возможности

- **Два режима конфигурации РЛС**
  - `MiG-29` — упрощённая модель РЛС Н019 с фиксированными параметрами (скорость сканирования 50 °/с, 4 строки растра, зона 50°, режимы «Авт./В/Д», смещение зоны влево/центр/вправо, ручка ΔH).
  - `Manual setup` — полностью ручная настройка всех параметров (дальность, азимут, ширина луча, число строк сканирования, скорость сканирования, наклон антенны, размер прицельного маркера и т.д.).
- **Два типа индикатора кругового обзора**
  - `PPI` — радиально-круговой (polar) индикатор.
  - `B-Scope` — прямоугольный индикатор «дальность × азимут» с затухающими отметками по строкам растра (для режима MiG-29 доступен только B-Scope).
- **3D-сцена (Three.js + OrbitControls)**: сектор обзора, активный луч сканирования, прицельный маркер (строб), земля, метки целей, вспышки обнаружения, подписи высот, ориентационные метки (север/вверх/вниз).
- **Боковая проекция** — зависимость азимут/дальность × высота для наглядной оценки эшелонов целей.
- **Управление целями**
  - Добавление цели в полярных координатах: смещение по азимуту (°), дальность (км), высота (км).
  - Добавление цели кликом по земле в 3D-сцене.
  - Удаление целей, наведение/подсветка (hover) цели синхронно во всех панелях.
- **Цветовая классификация целей**: в зоне обзора (FOV), в диапазоне/азимуте но вне угла места, вне азимута но в дальности, вне дальности — единая легенда во всех визуализациях.
- **Движение курсора (строба)** мышью по индикатору или стрелками клавиатуры, автопозиционирование на центр зоны обзора.

## Быстрый старт

### Требования

- **Node.js** ≥ 18 (рекомендуется LTS) и npm.
- Современный браузер с поддержкой WebGL (для 3D-сцены).

### Установка и запуск

```bash
# установка зависимостей
npm install

# запуск dev-сервера с горячей перезагрузкой
npm run dev

# сборка production-бандла (с проверкой типов через vue-tsc)
npm run build

# локальный предпросмотр собранной сборки
npm run preview
```

После `npm run dev` приложение будет доступно по адресу, который выведет Vite (по умолчанию http://localhost:5173).

## Как работает симуляция

1. **Цикл симуляции** (`SimulationLoop`) работает через `requestAnimationFrame` с **фиксированным шагом 1/60 с** и аккумулятором времени — это делает поведение сканирования независимым от частоты кадров.
2. **Движок** (`RadarEngine`) на каждом шаге:
   - сдвигает луч сканирования внутри зоны обзора по **растровой траектории** (построчно влево-вправо, затем возврат и переход на следующую строку по углу места);
   - вычисляет **обнаружения**: цель считается засвеченной, если она в пределах `maxRangeMeters` и попадает одновременно в луч по азимуту (`fovDeg`) и по углу места (эффективная ширина луча);
   - «Сила» отметки (`strength`) падает с ростом дальности (от 1 у РЛС до ~0.05 на границе зоны).
3. **Runtime** (`SimulationRuntime`) прокидывает кадр движка в `radarStore`, а позиции целей синхронизирует обратно в `targetsStore`.
4. **Рендереры** — «чистые» классы без обращения к Vue: получают снимок состояния (props) и перерисовываются по `watch` в соответствующих панелях. 3D-сцена имеет собственный цикл отрисовки.

### Ключевые параметры РЛС (`RadarParams`)

| Параметр | Описание | Диапазон |
| --- | --- | --- |
| `maxRangeMeters` | Максимальная дальность обзора, м | 20 000 – 200 000 |
| `radarAltitudeMeters` | Высота РЛС над землёй, м | −500 – 25 000 |
| `radarAzimuthDeg` | Азимут (курс) РЛС, ° | −180 – 180 |
| `fovDeg` | Ширина луча по азимуту, ° | 1 – 40 |
| `beamElevationDeg` | Ширина луча по углу места, ° | 1 – 45 |
| `scanLinesCount` | Число строк растра сканирования | 1 – 60 |
| `autoBeamElevationByScanLines` | Авто-выбор ширины луча по числу строк (непрерывное покрытие) | bool |
| `elevationFovDeg` | Угловой размер зоны по углу места, ° | 5 – 90 |
| `scanSpeedDegPerSec` | Скорость сканирования, °/с | 20 – 360 |
| `azimuthScanSpanDeg` | Сектор сканирования по азимуту, ° (360 = круговой обзор) | 10 – 360 |
| `antennaTiltDeg` | Наклон антенны (по оси угла места), ° | −60 – 60 |
| `zoneAzimuthOffsetDeg` | Смещение зоны обзора по азимуту, ° | −180 – 180 |
| `cursorWidthMeters` / `cursorLengthMeters` | Размеры прицельного строба, м | 500 – 20 000 |

Пресеты дальности в режиме MiG-29: `Авт.` — 100 км, `В` — 150 км, `Д` — 50 км, с соответствующими зонами по углу места.

## Руководство по интерфейсу

- **Верхняя панель** — заголовок, счётчики (время симуляции, число целей и обнаружений) и кнопка `Run/Pause`.
- **Слева** — виджет целей (список с азимутом/дальностью/высотой и их статусом) и 3D-сцена.
  - Клик по земле в 3D — добавить цель.
  - Нижняя панель 3D — переключатели отображения (полный сектор, вертикальные грани, активный сектор, ориентационные метки, подписи высот) и кнопки центрирования камеры.
- **По центру** — панель параметров РЛС: выбор конфигурации (`MiG-29` / `Manual setup`), режимы, пресеты, слайдеры.
- **Справа сверху** — боковая проекция (дальность × высота); наведение курсора подсвечивает цель.
- **Справа снизу** — индикатор РЛС (PPI/B-Scope): клик ЛКМ задаёт положение строба, есть переключатели «луч на индикаторе» и «сетка».
- **Клавиатура** — стрелки `↑/↓` двигают строб по дальности, `←/→` — по азимуту (когда фокус не в поле ввода).

### Цветовая легенда целей

- **Красные** (пирамида) — в зоне обзора (в пределах дальности, азимута и угла места).
- **Жёлтые** (куб) — в пределах дальности и азимута, но вне угла места.
- **Зелёные** (сфера) — вне азимута зоны, но в пределах дальности.
- **Серые** (сфера) — вне дальности.

## Заметки и ограничения

- Модель **упрощённая и учебная**: это не точная реконструкция реальной РЛС Н019, а наглядная визуализация механики обзора (растр, зона, строб, обнаружение по геометрии).
- Обнаружение рассчитывается **геометрически** (попадание в луч по азимуту/углу места и в пределы дальности), без учёта ЭПР, радиогоризонта, помех, доплеровской фильтрации и т.п.
- Все расчёты выполняются на клиенте в браузере; бэкенд отсутствует.
- Проект находится в ранней стадии разработки.
